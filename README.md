## Data retrieval instructions

In every .qmd file, we have programatical retrieval of the data directly from the source.

Nevertheless, if by any means, the cell fails to run, bellow are the instructions for manual retrieval of the data:

#### Manual retrieval of data:

The datasets used in this project were obtained from zenodo database.

**Dataset 1: Sample metadata**

-   Original file: "RNA_sample_metadata.txt.gz"

-   Source: <https://zenodo.org/records/259661>

-   Instructions: Download the file and place it in the `_raw/` directory.

**Dataset 2: RNA count matrix**

-   Original file: "RNA_count_matrix.txt.gz"

-   Source: <https://zenodo.org/records/259661>

-   Instructions: Download the file and place it in the `_raw/` directory.

**Dataset 3: RNA cqn count matrix**

-   Original file: "RNA_cqn_matrix.txt.gz"

-   Source: <https://zenodo.org/records/259661>

-   Instructions: Download the file and place it in the `_raw/` directory.
