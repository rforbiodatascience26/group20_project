Normalised Counts data

Filter low count genes

The authors of the original paper did not filter low-count genes before normalisation (nor do they mention such action), so we used the raw counts to identify them. Genes with consistently low read counts were removed to reduce their influence on the analysis: only genes with at least 10 counts in a minimum of 80 samples were retained

clean_counts_raw_df <- counts_raw_df |>
  filter(rowSums(across(-1) >= 10) >= 80)

We use semi_join() to remove the same genes from the normalised data. This function keeps only the rows of counts_norm whose gene_id also appears in the filtered raw data, without adding any columns from it.

clean_counts_norm_df <- counts_norm_df |>
  semi_join(clean_counts_raw_df, by = "gene_id")

Analysis of Data - PCA Plot

At the start of the exploratory analysis, it is usual to perform a Principal Component Analysis (PCA) to evaluate global variation in the dataset and check whether samples separate according to their experimental conditions.

To prepare the data for PCA, we first reshaped merged_data into a wide format (merged_data_PCA) using pivot_wider(), so that each row represents a single sample and each column corresponds to a gene’s normalized expression (log2_counts).

merged_data_PCA <- merged_data |>
  select(c("gene_id","sample_id","log2_counts", "condition_name")) |>
  pivot_wider(names_from = gene_id, values_from = log2_counts)

Next, we selected only the numeric columns (the gene expression values) and computed the principal components using prcomp(scale = TRUE). Scaling standardizes the variables so that genes with higher overall expression levels do not dominate the variance calculation.

pca_fit <- merged_data_PCA |> 
  select(where(is.numeric)) |>  
  prcomp(scale = TRUE)

Finally, we projected the samples onto the first two principal components (PC1 and PC2) using fviz_pca_ind(). Samples were colored by condition_name and grouped with 95% confidence ellipses to visualize clustering across the four treatments.

pca_plot <- fviz_pca_ind(
  pca_fit,
  geom.ind = "point",
  col.ind = merged_data_PCA$condition_name,
  palette = "jco",
  addEllipses = TRUE,
  ellipse.level = 0.95,
  legend.title = "Condition"
) +
  theme_minimal() +
  labs(
    title = "PCA Plot Mapping the 4 conditions",
    subtitle = "Projection of samples onto PC1 and PC2",
    caption = "Plot Design (used on Lab07) from \nhttps://www.r-bloggers.com/2026/06/pca-in-r-principal-component-analysis-step-by-step-prcomp-ggplot2/#google_vignette"
  ) +
  theme(
    plot.caption = element_text(hjust = 0, size = 8, color = "gray30")
  )

As shown in the PCA plot, the samples separate cleanly into four distinct clusters corresponding to the experimental conditions (naive, IFNg, SL1344, and IFNg_SL1344). This shows that the main source of variation in the dataset is driven by the biological treatments rather than technical effects.
