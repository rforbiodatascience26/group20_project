Normalised Counts data

Filter low count genes

The authors of the original paper did not filter low-count genes before normalisation (nor do they mention such action), so we used the raw counts to identify them. Genes with consistently low read counts were removed to reduce their influence on the analysis: only genes with at least 10 counts in a minimum of 80 samples were retained

clean_counts_raw_df <- counts_raw_df |>
  filter(rowSums(across(-1) >= 10) >= 80)

We use semi_join() to remove the same genes from the normalised data. This function keeps only the rows of counts_norm whose gene_id also appears in the filtered raw data, without adding any columns from it.

clean_counts_norm_df <- counts_norm_df |>
  semi_join(clean_counts_raw_df, by = "gene_id")

Analysis of Data

Infected Cells

To be able to see the differences in gene expressions in infected cells, we kept only the infected samples. Within these samples, the two groups to compare are the naive and the primed cells. We then converted IFNg_status into a factor with “naive” as the first level (set to be the reference).

compare_infected <- merged_data |>
  filter(SL1344_infection == "infected") |>
  mutate(IFNg_status = factor(IFNg_status, levels = c("naive", "primed")))

Selected the columns needed for the model and nested the data by gene_id.

compare_infected_nested <- compare_infected |>
  select(c("gene_id","sample_id","log2_counts","IFNg_status")) |>
  group_by(gene_id) |>
  nest() |>
  ungroup()

compare_infected_nested |>
  slice_sample(n=10)

Fit a linear model for every gene. We use mutate() together with map(), which applies the same function to each element of data column. The function is lm() with the formula “log2_counts ~ IFNg_status”.

For each gene, the model estimates the mean expression in naive cells (the intercept) and the difference between primed and naive cells. Since the values are on a log2 scale, this difference is the log2 fold change.

compare_infected_nested <- compare_infected_nested |> 
  mutate(model_object = map(.x = data,
                            .f = ~lm(formula = log2_counts ~ IFNg_status,
                            data = .x)))

We used tidy() from broom library to convert each model into a table of estimates, p-values and confidence intervals.

compare_infected_nested <- compare_infected_nested |> 
  mutate(model_object_tidy = map(.x = model_object,
                                 .f = ~ tidy(.x, conf.int = TRUE, conf.level = 0.95)))

Unnest the data

estimates_infected <- compare_infected_nested |> 
  unnest(model_object_tidy)

From the unnested results we kept only the relevant rows and the columns needed for further analysis.

We do a multiple testing correction, ajusting the p.values using p.adjust(), which gives the q.value. Finally, we used case_when() to classify each gene in a new column: a gene is “up” if q.value < 0.05 and the log2 fold change is above 1 (at least twofold higher in primed cells); “down” if q.value < 0.05 and the log2 fold change is below -1 (at least twofold lower in primed cells), and “not significant” otherwise (q.value >= 0.05) .

estimates_infected <- estimates_infected |> 
  filter(term == "IFNg_statusprimed") |> 
  select(gene_id, term, estimate, std.error, statistic, p.value, conf.low, conf.high) |> 
  ungroup() |> 
  mutate(q.value = p.adjust(p.value),
         sign = case_when(q.value < 0.05 & estimate >  0.59 ~ "up",
                          q.value < 0.05 & estimate < -0.59 ~ "down",
                          TRUE ~ "not significant"))

Visualise

Volcano Plot : Changes in gene expression in infected cells when primed with IFNg

We selected the ten genes with the largest absolute log2 fold change to label them on the plot.

top_genes <- estimates_infected |>
  slice_max(abs(estimate), n = 10) |>
  pull(gene_id)

We added a column that holds the gene_id for the ten selected genes and an empty label for all others, so that only those ten are labelled on the plot.

estimates_infected <- estimates_infected |>
  mutate(top10 = case_when(gene_id %in% top_genes ~ gene_id,
                           !(gene_id %in% top_genes) ~ ""))

Plotted with ggplot.
